# Terraform Datadog Baseline

Reusable Terraform modules for building production-ready Datadog observability on AWS.

## Features

- Amazon EKS monitors
- SLO burn-rate alerts
- RDS monitors
- ALB monitors
- ECS/Fargate monitors
- Lambda monitors
- Standardized tagging

## Requirements

- Terraform >=1.5
- Datadog Provider
